Case Study

STM32 + HC-SR04 Water Level Measurement + TouchGFX UI

Embedded firmware and UI experience that provides clear tank-level feedback, calibration, and alarms.

Problem

Operators needed a reliable, easy-to-read UI for water tank levels without manual measurements. The system had to update quickly and visually indicate alarms.

Constraints

Sensor noise from reflections, limited MCU resources for UI rendering, and the need to support calibration in-field.

System design

Built a layered architecture: sensor driver → filtering and conversion → UI model → TouchGFX view. Implemented a moving-average filter and configurable thresholds.

Implementation

Configured STM32 timers for echo capture, wrote a distance conversion routine, and implemented a TouchGFX dashboard with color-coded alarms and calibration prompts.

Results

Achieved stable readings within ±1.5 cm in lab tests (estimate) and reduced UI update latency to ~200 ms. User feedback reported faster decision-making during fill/empty cycles.

What I’d improve next

Add temperature compensation, implement a sensor health check, and capture data logs for predictive maintenance.
