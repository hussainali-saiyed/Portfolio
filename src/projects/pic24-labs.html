Case Study

PIC24 Embedded Labs

Structured lab work focused on core MCU peripherals and reusable firmware patterns.

Problem

Labs were inconsistent and difficult to reuse across cohorts. A more structured, repeatable lab set was needed to accelerate learning and reduce setup time.

Constraints

Limited lab time and shared hardware. The workflows had to be easy to reset and validate without specialized equipment.

System design

Created a base firmware template with driver hooks for timers, interrupts, ADC, and UART. Designed a checklist-based validation flow to ensure repeatability.

Implementation

Wrote timer and UART drivers, added interrupt-driven ADC sampling, and built a serial console for rapid verification. Packaged lab notes with troubleshooting steps.

Results

Reduced setup time by ~25% (estimate) and improved lab completion rates. Students reported clearer debugging steps and faster progress between modules.

What I’d improve next

Add automated unit tests on the peripheral drivers and provide a visualization dashboard for UART logs.
