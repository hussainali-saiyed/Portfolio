Case Study

Smart Recirculating Aquaculture System (RAS) Prototype

Prototype system integrating sensors, microcontroller control, and pump automation to keep water quality stable for a small-scale aquaculture loop.

Problem

Manual monitoring of pH, dissolved oxygen, and temperature was inconsistent and delayed. The goal was to build a continuous monitoring system with automated pump and flow control to stabilize water quality in near real time.

Constraints

Sensors needed frequent calibration, budget was limited to off-the-shelf components, and the system had to run unattended for 24/7 sampling. A simple UI was required for non-technical operators.

System design

Selected a modular architecture: sensor cluster → MCU data acquisition → pump control relay board → UI dashboard. Implemented alarms for high ammonia risk using proxy thresholds (estimate-based).

Implementation

Integrated pH, DO, temperature, and flow sensors with an Arduino-class MCU. Built control firmware to adjust pump cycles based on flow feedback and scheduled backwash routines to reduce clogging.

Results

Achieved continuous logging at 1 Hz with alerting. Reduced manual water checks by an estimated 60% and improved daily stability of dissolved oxygen by ~15% (estimate from pilot runs).

What I’d improve next

Add a redundancy sensor for DO, implement PID tuning for pump control, and deploy a predictive model for ammonia risk to preempt spikes.
