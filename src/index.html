About

Engineer with hands-on build experience

I build systems where hardware and software meet. My work spans sensor integration, actuator control, mechanical design, and field validation. I treat each project as a system: define the problem, quantify constraints, design for testability, and iterate until it performs reliably.

I value clear documentation, structured experiments, and measurable outcomes. When data is uncertain, I mark estimates and share the assumptions, so stakeholders can make informed decisions quickly.
